*Июль 2023 — настоящее время*

Занимался переписыванием на современный стек различных систем для интеграции в заводы и лаборатории, разрабатывал новые.

 - Система управления лабораторией: перенёс функциональность работы с химическими образцами из legacy-системы на ASP.NET и WinForms в новое приложение (микросервисы, Clean Architecture): разрабатывал backend на ASP.NET Core и frontend на Angular; обеспечил совместимость данных при переходе.

 - Взаимодействие backend с внутренним frontend-фреймворком: реализация кастомной фильтрации для таблиц, управление видимостью UI-компонентов на основе claims.
 - Разрабатывал систему хранения и обработки временных рядов, участвовал в миграции с Cassandra на ClickHouse, реализовывал сбор данных и механизмы синхронизации сервисов.
 - Реализация и поддержка микросервисов для сбора данных из внешних баз временных рядов и передачи их во внутренние сервисы.

 - Интеграция с нефтеперерабатывающим предприятием: реализовал модель анализа материального баланса установок, алгоритм выявления расхождений в отчётности и отображение результатов на Angular.

*C#. ASP.NET Core. Entity Framework и Dapper (для более сложных запросов). База данных как PostgreSQL, так и Ms sql. Брокер сообщений - Kafka с библиотекой MassTransit. Метрики через Prometheus и Grafana. Оркестрация через Kubernetes. Релизы через пайплайны TFS CI/CD.*
